# Pixel Tiers

Minecraft PvP tier rankings site. Express + EJS front end (`server.js`, `views/`, `public/assets/`).

Theme: "Night Arcade" (navy checkerboard, gold accents, pixel borders). Logo and icons are in `public/assets/`.

Note: `server.js` expects a `../shared/` folder (gamemodes, tiers) and a database that are not part of this repo.

## Preview without the bot or database

`npm install && npm start` runs `demo-server.js`, which serves the real pages with sample players. The production server is `server.js`.
